# Changelog

All notable changes are documented here. The project follows semantic versioning where practical.

## [0.1.0] — 2026-08-21

### Added

- Canonical cell/cycle/timeseries/protocol schemas and group-aware split enforcement.
- Early-cycle feature pipeline with hard future-information leakage checks.
- B0 median, B1 linear, and B2 XGBoost model ladder with grouped evaluation.
- Split-conformal intervals, Mahalanobis OOD, explicit abstention, nearest cells, and risk fingerprinting.
- Deterministic Twin-0 strategy simulator, bounded policy library, Pareto search, and independent `SafetyShield`.
- One-time controlled synthetic reveal/access-control rehearsal and hash-chained append-only Evidence Ledger with chain-head checkpoint.
- Shared CLI, FastAPI, and Streamlit product surfaces plus Docker packaging.
- A dated automated test/coverage snapshot, strict typing, lint, Python 3.11–3.13 CI, offline rehearsal, and non-root container smoke gates.

### Boundaries

- All bundled evaluation data and reported numerical results are synthetic.
- The public synthetic generator and static walkthrough are not an independent blind benchmark.
- No hardware-control interface is included or permitted by the current safety case.
