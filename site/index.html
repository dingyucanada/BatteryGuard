HARD BOUNDARY

这不是 BMS。
也不是充电控制器。This is not a BMS.
It is not a charging controller.

BatteryGuard 是一个离线、软件专用的研发原型。仓库故意不包含硬件传输、设备 SDK、CAN、充电协议或执行端点。BatteryGuard is an offline, software-only research prototype. The repository intentionally contains no hardware transport, device SDK, CAN, charger protocol, or actuation endpoint.
